Kiểm tra sao kê ngân hàng

Tải file PDF sao kê lên để tìm dấu hiệu chỉnh sửa hoặc làm giả. File chỉ được phân tích trên máy chủ này và bị xoá ngay sau khi kiểm tra.

Kết quả chỉ là cảnh báo dựa trên dấu hiệu kỹ thuật, không phải kết luận pháp lý. Luôn xác minh trực tiếp với ngân hàng phát hành khi có nghi ngờ.
